📊 Sales Database System
Este projeto apresenta a estrutura de um banco de dados relacional desenvolvido em SQL para gerenciar o fluxo básico de um sistema de vendas. Ele abrange desde o cadastro de clientes até o registro de pagamentos, garantindo a integridade dos dados através de chaves estrangeiras.

🛠️ Estrutura do Banco de Dados
O sistema é composto por 5 tabelas principais:

Clientes: Armazena informações básicas como nome e e-mail único.

Produtos: Catálogo de itens disponíveis com seus respectivos preços.

Pedidos: Registra a data e vincula a transação a um cliente específico.

Itens do Pedido: Tabela de relacionamento que permite múltiplos produtos por pedido.

Pagamentos: Controle dos valores recebidos para cada pedido realizado.

🚀 Como utilizar
Certifique-se de ter um ambiente SQL (como PostgreSQL) configurado.

Execute o script contido no arquivo MyFirstSoftware.sql para criar as tabelas e inserir os dados iniciais.

Utilize as consultas (SELECT) ao final do arquivo para verificar a consistência dos dados inseridos.

💻 Tecnologias
Linguagem: SQL (DDL/DML).

Paradigma: Banco de Dados Relacional.
